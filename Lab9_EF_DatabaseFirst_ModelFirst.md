# Лабораторная №9: демонстрация подходов Database First и Model First

В этом проекте рабочая часть реализована через **Code First + Fluent API** (файлы `Data/MedicalCenterDbContext.cs` и `Data/Entities/*`).

Ниже приведена инструкция, как на защите показать два альтернативных подхода Entity Framework:
- **Database First** (сначала база, потом модель);
- **Model First** (сначала модель, потом база).

## Подготовка перед демонстрацией

1. Убедиться, что проект собирается и пакет `EntityFramework` подключен.
2. Убедиться, что SQL Server доступен и можно создать/подключить БД.
3. Открыть проект в **Visual Studio** (не в режиме только чтения).

---

## 1) Database First (из готовой БД в модель)

### Что показываем
Получение `.edmx`-модели и C#-классов из уже существующей базы данных.

### Пошагово
1. В Visual Studio (русская локализация) выбрать: `Проект -> Добавить -> Создать элемент...`.
2. В окне шаблонов выбрать: `Модель данных ADO.NET` (в некоторых версиях название остается `ADO.NET Entity Data Model`).
3. Задать имя, например: `MedicalCenterDbFirst.edmx`.
4. В мастере выбрать вариант: `Конструктор EF из базы данных` (`EF Designer from database`).
5. Создать новое подключение или выбрать существующее к БД `MedicalCenter`.
6. В мастере отметить таблицы:
   - `Departments`
   - `MedicalServices`
   - `ServiceTimeSlots`
   - `Appointments`
   - `AuditLog`
7. Нажать `Готово` (`Finish`).

### Итог демонстрации
- в проекте появляется файл `.edmx`;
- Entity Framework генерирует классы сущностей и контекст;
- можно выполнять запросы через сгенерированный контекст без ручного описания модели.

---

## 2) Model First (из модели в БД)

### Что показываем
Проектирование модели в дизайнере EF и генерацию SQL-скрипта базы.

### Пошагово
1. В Visual Studio выбрать: `Проект -> Добавить -> Создать элемент...`.
2. Выбрать шаблон: `Модель данных ADO.NET` (или `ADO.NET Entity Data Model`).
3. Задать имя, например: `MedicalCenterModelFirst.edmx`.
4. В мастере выбрать вариант: `Пустая модель конструктора EF` (`Empty EF Designer model`).
5. В дизайнере добавить сущности и настроить связи:
   - `Department` 1..* `MedicalService`;
   - `MedicalService` 1..* `ServiceTimeSlot`;
   - `MedicalService` 1..* `Appointment`.
6. Нажать правой кнопкой по поверхности модели и выбрать `Создать базу данных по модели...` (`Generate Database from Model`).
7. Указать подключение к SQL Server.
8. Выполнить сгенерированный SQL-скрипт (создание таблиц, ключей и ограничений).

### Итог демонстрации
- из визуальной модели генерируется схема базы данных;
- при необходимости можно сгенерировать классы и использовать их в коде.

---

## Что важно проговорить на защите

- В данном проекте **основной рабочий код** использует Code First.
- Database First и Model First представлены как **демонстрация альтернатив** в рамках требований лабораторной работы.
- Эти подходы не конфликтуют с текущей архитектурой проекта и показывают разные способы работы EF с моделью данных.
